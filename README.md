# 轻账 · 个人记账网页

中文个人记账本：添加收支、按月查看收入/支出/结余、支出分类占比、账目明细及确认删除。适配电脑和手机，无需安装依赖。

## 使用

直接打开 `index.html`，或使用 Node.js 22 及以上版本启动本地预览：

```sh
node server.js
```

访问 http://127.0.0.1:4173 。推荐固定使用此地址，浏览器存储按地址隔离。

## 数据

金额按整数分计算。账目保存于当前浏览器 localStorage，不会上传 GitHub 或服务器，不支持跨设备同步。清除浏览器数据、无痕模式或更换浏览器可能导致账目丢失或无法访问，请勿作为重要财务数据的唯一存档。损坏的数据不会被自动覆盖。初始页面为空。

## 测试

```sh
node --test tests/ledger.test.js
node --check app.js
node --check ledger.js
```

覆盖金额精度及校验、月度与年度隔离、分类统计、日期校验、存储损坏保护和删除后重算。界面交互另通过浏览器验证。

## 文件

- `index.html` / `styles.css`：中文响应式页面
- `ledger.js`：数据校验和统计
- `app.js`：表单、页面渲染及持久化
- `server.js`：仅监听本机、仅提供网页资源的预览服务器

推送源码到 GitHub 不等于部署网站；四个网页文件也可以部署到静态托管服务。
